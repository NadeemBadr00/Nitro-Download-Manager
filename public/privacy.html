Privacy Policy for Nitro Download Manager

Last Updated: August 19, 2026 | Publisher: Nadeem Badr (nbra.in)

1. Overview

Nitro Download Manager ("NDM", "we", "our") is committed to protecting your privacy. This Privacy Policy explains how our Chrome Extension and desktop software handle user information.

2. Data Collection and Usage

We do not collect, transmit, store, or sell any personal user data.

  • No Analytics or Tracking: The extension contains zero tracking pixels, telemetry, or third-party analytics SDKs.
  • No Remote Server Logging: All file downloading, video stream detection, and acceleration algorithms execute 100% locally on your own machine.
  • No Browsing History Stored: URLs detected by the video sniffer are processed in volatile memory only to fetch stream quality manifests.

3. Chrome Extension Permissions Justification

  • downloads: Required strictly to intercept browser downloads and facilitate multi-threaded chunked downloads.
  • storage: Used solely to save your local UI preferences (e.g. speed limiter, notification toggles, theme) in your local browser storage.
  • contextMenus: Enables the right-click "Download with Nitro DM" option on links and media files.
  • host_permissions: Needed to communicate with the local Nitro DM background engine at http://localhost:3000 and parse media streams on supported web pages.

4. Data Security

Because all operations run locally, your download history and preferences remain on your local computer at all times.
